==================================================

[ ] تثبيت Windows Server / التأكد من صلاحيات Administrator

[ ] تثبيت Node.js LTS
[ ] تثبيت Git
[ ] تثبيت NSSM
[ ] تثبيت cloudflared إذا كان مستخدما
[ ] فتح Firewall للمنفذ 5001 عند الحاجة
[ ] فتح أي منفذ إضافي مطلوب للواجهة أو الخدمات
[ ] إنشاء مجلد ثابت للمشروع مثل:
    C:\Apps\OpenClaw_Version

==================================================

[ ] نسخ ملفات المشروع إلى السيرفر الجديد

4. Python Environment
==================================================

[ ] إنشاء البيئة الافتراضية:
    python -m venv .venv
[ ] تفعيل البيئة:
    .venv\Scripts\Activate.ps1
[ ] تحديث pip:
    python -m pip install --upgrade pip wheel
[ ] تثبيت الحزم:
    pip install -r requirements_runtime_freeze.txt
[ ] تشغيل اختبار سريع:
    python ai_agent.py
[ ] التأكد أن المنفذ 5001 يعمل
